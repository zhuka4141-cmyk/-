# 赛车拆解与涂鸦工作台

纯静态网页，默认加载随项目提供的 `huh.step`，支持五组部件拆解和表面涂鸦。

## 运行

```sh
python -m http.server 8080
```

打开 http://localhost:8080 。也可以直接把整个项目部署到 GitHub Pages。依赖及许可证均在 `vendor/`，运行时不需要 CDN。请使用现代 WebGL 浏览器，通过 HTTPS 或 localhost 访问；直接双击 HTML 的 `file://` 模式不支持模块、Worker 和 WASM 加载。

## 操作

- 点击前翼、后翼、轮子、轮子支撑或 Halo，独立拆开/复位该组。
- “全部拆开 / 全部复位”控制整车，“拆解距离”调整分离程度。
- 左键拖动旋转、右键平移、滚轮或双指缩放；“适应视图”重新取景。
- 默认“自动”模式下，Apple Pencil（`pointerType=pen`）直接画笔，手指（`pointerType=touch`）直接旋转/缩放，不需要切换；也可手动选择“旋转查看”或“画笔”。涂鸦跟随零件移动，支持撤销、清空、导入和导出。
- 画笔支持压力大小/透明度、透明度滑杆、柔边/硬边、橡皮、撤销/重做，并使用 Pencil 的高频合并采样降低断线和锯齿。
- 涂鸦按模型文件 SHA-256 分开缓存，刷新后自动恢复。自动保存失败时请使用“导出涂鸦”。
- 手机可收起“部件拆解”，在底部工具区滚动使用画笔。

## 模型结构与限制

`huh.step` 共 20 个实体、41,250 个三角面（当前解析参数）。五组对应：前翼 3、后翼 2、轮子及轮毂 5、独立支撑 7、Halo 1；头盔和车身固定。

源 CAD 中两侧前翼与部分前轮支架为连体实体，随前翼移动。独立支撑可单独拆解。本项目不切割或改变 CAD 几何。

解析器不保留大部分实体名称，因此内置车型使用经过装配和几何核对的映射，仅对 SHA-256 `2d6ae7e96737f5ebbc635e9d98273d3401c86a189c312e787f6bba7c9eb05a29` 生效。其它 STEP/STP 只按可识别的零件名称归组，无名实体保持固定；方向约定为 +Y 向上、+Z 车头、X 左右。替换长期使用的默认车型时应重新核对映射。

模型上限 50 MB，涂鸦数量没有应用层上限，实际可用量受设备内存和浏览器存储空间影响。旧版整车坐标涂鸦不自动迁移，避免落到错误零件；导入时给出说明。原有 v1 本地缓存保持独立。

## 文件职责

- `index.html` / `style.css`：界面和响应式布局。
- `app.js`：交互、相机、模型加载和本机保存。
- `model.js`：零件网格、分组和可逆拆解动画。
- `paint.js`：零件局部坐标贴花、表面索引、数据校验和恢复。
- `step-worker.js`：后台解析 STEP，避免阻塞界面。
- `vendor/`：Three.js 0.160.0、occt-import-js 0.0.23 及许可证。

## 开发与验证

需要 Node.js 22 或更高版本：

```sh
npm ci
npm test
npm run vendor
```

测试使用真实 huh.step，检查所有实体保留、五组映射、轮子左右分离、精确复位、涂鸦随动、跨模型和损坏数据拒绝。`npm run vendor` 只用于重新生成固定版本依赖，站点日常运行不需要 Node.js。

桌面端与手机端的最终视觉验收受本次环境的浏览器自动审查服务故障影响，未完成。已确认页面请求的模块、STEP、Worker 与 WASM 均返回 HTTP 200；这不等同于完整交互验收。
