# 赛车部件拆解

用户已确认：以 huh.step 替换默认车，保留涂鸦，使用五组按钮、全部拆开、全部复位及距离滑杆。

保持静态网站架构、Three.js r160 和 occt-import-js 0.0.23。拆出样式、应用入口、装配逻辑与涂鸦逻辑。每个实体保留独立 Mesh、稳定 ID、原始几何坐标；拆解仅平移 Mesh。贴花和空间索引使用实体局部坐标，贴花挂在实体下，导出带实体 ID 和模型内容指纹，避免换车后恢复错误涂鸦。

已实际解析 huh.step，共 20 个网格。默认文件按内容指纹绑定已核对的实体映射：轮子 0–4（含轮毂）；后翼 6–7；Halo 8；前翼 9、10、14；轮子支撑 11–13、15–18；头盔 5 和车身 19 固定。前翼侧板和前轮支架在源模型中是连体实体，不切割 CAD 几何，随前翼移动。其余支撑独立拆解。未知外部 STEP 仅按可识别的名称归组，不猜测无名实体。

默认车的长轴为 Z，前方为 +Z，上方为 +Y；轮子左右沿 X 外移、支撑较近距离向外/下移、前翼向前、后翼向后/上、Halo 向上。动画可逆，复位精确归零，尊重减少动态效果设置。拆解距离在 0–150% 内调整。

延续现有深色和橙色控件，在桌面左侧安排部件面板，手机使用底部可收起面板。视口避让面板，按钮有可访问名称与按下状态，加载期间禁止编辑。无可识别部件时显示说明。

模型加载失败保留上一个模型；只接受 STEP/STP，涂鸦 JSON 在清除现有涂鸦之前验证模型指纹、实体 ID、有限坐标和数量上限。保存失败给出提示。依赖随站点提供以便本地/静态部署无需 CDN。

验收：真实 STEP 的 20 个网格完整；五组可独立/全部拆开及复位；涂鸦在拆解、复位、保存恢复后跟随原实体；跨模型数据拒绝导入；桌面与手机界面可操作；可直接部署 GitHub Pages。
