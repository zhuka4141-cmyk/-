# 涂鸦工作台升级设计

目标是把当前“连续生成贴花”的涂鸦功能升级为平板优先的模型表面绘画工具。自动输入模式按 Pointer Events 区分 Apple Pencil（`pen`）和手指（`touch`）：笔绘画，手指交给 OrbitControls 做旋转、缩放和平移；鼠标仍可选择手动模式。绘画继续使用零件局部坐标，保证拆解后笔画跟随零件。

## 用户体验

绘画面板提供自动、旋转查看、画笔三种模式；自动是默认模式。画笔工具栏提供颜色、大小、透明度、压力控制开关、柔边/硬边笔刷、橡皮、撤销、重做、清空和导出。画布显示笔刷圆环预览、压力数值和当前零件名称。Pencil 的 `pressure` 控制大小和透明度，设备未提供有效压力时使用固定值；使用 `getCoalescedEvents()` 消化 Pencil 高频采样，插值间距按屏幕像素和模型尺寸共同限制。

橡皮按命中的零件和笔画包围球删除整笔，提供撤销恢复。涂鸦导出版本升到 3，保留版本 2 的只读导入兼容；每个印记保存压力、透明度、工具和局部坐标。撤销/重做只操作完整笔画，清空前保留确认。

## 架构

`interaction.js` 只负责输入分类、压力归一化和采样点压缩；`paint.js` 负责笔刷材质、贴花、橡皮命中和 v3 数据校验；`app.js` 负责 UI 状态、撤销/重做栈、自动保存和 Three.js 事件。画笔材质改为每个贴花保存 opacity，避免后续调节影响旧笔画。模型和拆解逻辑不改变。

## 边界与验收

不新增服务器和账号功能。最大 6,000 个印记继续保留，超过时提示导出/清空。透明度、压力、软硬笔刷和橡皮均有纯函数测试。桌面鼠标、触摸手指和笔输入必须各自进入正确路径；模型拆解、撤销/重做、导入/导出和刷新恢复必须通过已有及新增测试。
